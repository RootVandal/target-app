# TARGET: мини-приложение для Telegram

Маленькая статичная страница, которая показывает код для входа в TARGET крупно, прямо в Telegram.
Бот присылает код сообщением и кнопку «Открыть TARGET». Кнопка открывает эту страницу: шесть цифр,
кольцо обратного отсчёта, «Скопировать код» и «Закрыть». Код вводится на сайте TARGET на компьютере.

Файлы: `index.html`, `app.css`, `app.js`. Сборки нет, зависимостей нет.

## Как код попадает на страницу

Бот открывает адрес вида

```
https://ваш-ник.github.io/target-app/#c=482913&exp=1763550000&n=%D0%A2%D0%B8%D0%BC%D1%83%D1%80
```

- `c` ровно 6 цифр, `exp` время истечения (unix, секунды), `n` имя из Telegram (в URL-кодировке, необязательно).
- Всё стоит после `#`, во фрагменте. Браузер не отправляет фрагмент на сервер, поэтому GitHub код не видит.
- Страница проверяет фрагмент строго: неверный код, нет срока или срок дальше ±2 суток от текущего времени
  дают экран «Кода пока нет». Имя очищается от управляющих символов, обрезается до 32 знаков и выводится только как текст.
- Сразу после чтения фрагмент стирается из адресной строки (`history.replaceState`). Остаются только служебные
  параметры Telegram `tgWebApp…`, они нужны его SDK. SDK подключается уже после этого и кода не видит.
- Чтобы код пережил «Перезагрузить страницу» внутри Telegram, он лежит в `sessionStorage` этой вкладки и удаляется, когда истекает.

## Что страница делает в сети

Ничего не отправляет. Загружаются только:

- шрифты Inter Tight, Inter и JetBrains Mono с Google Fonts;
- `https://telegram.org/js/telegram-web-app.js` (SDK мини-приложений).

Это закреплено политикой CSP в `index.html` (`connect-src 'none'`, скрипты только свои и с telegram.org).
Аналитики нет. Если не хотите, чтобы Google видел запрос шрифтов, удалите три строки `<link … fonts…>` в `index.html`:
страница возьмёт системные шрифты и останется рабочей.

## Размещение на GitHub Pages

1. Создайте на GitHub новый **публичный** репозиторий, например `target-app`
   (Pages для приватных репозиториев есть только на платных тарифах).
2. Загрузите в корень репозитория три файла: `index.html`, `app.css`, `app.js`
   (кнопка «Add file», затем «Upload files»). `README.md` можно не загружать.
3. Откройте **Settings**, затем **Pages**. В блоке **Build and deployment** выберите
   Source: **Deploy from a branch**, Branch: **main**, папка **/ (root)**, нажмите **Save**.
4. Через минуту-две вверху той же страницы появится адрес вида `https://ваш-ник.github.io/target-app/`.
5. Проверьте его в обычном браузере: без кода откроется экран «Кода пока нет».
   С пробным кодом: допишите к адресу `#c=123456&exp=` и текущее время unix плюс 300
   (его можно взять на любом сайте «unix time now»). Должны появиться цифры и отсчёт.

Подойдёт любой другой хостинг статических файлов, главное, чтобы адрес был **https**: Telegram открывает мини-приложения только по https.

## Подключение к TARGET

1. В TARGET откройте **Настройки**, раздел **«Вход и Telegram-бот»**.
2. В поле **«Адрес мини-приложения (https)»** вставьте адрес из шага 4, например `https://ваш-ник.github.io/target-app/`.
3. Нажмите большую кнопку **«Сохранить»** формы настроек.

Готово: при следующем входе бот добавит к сообщению с кодом кнопку «Открыть TARGET».
Если поле пустое или адрес не https, бот присылает только текст с кодом, вход работает так же.

Регистрировать мини-приложение в @BotFather не нужно: кнопка с `web_app` в сообщении бота работает с любым https-адресом.

## Посмотреть локально

```
cd miniapp
python -m http.server 8900 --bind 127.0.0.1
```

Откройте `http://127.0.0.1:8900/#c=482913&exp=<unix-время через 5 минут>&n=Тимур`.
Вне Telegram страница работает так же, только без вибрации и без кнопки «Закрыть».
Порт 8811 занят самим TARGET, для предпросмотра берите любой другой.

## Поведение

- Шесть ячеек откидываются по очереди, как на табло; в Telegram каждая отзывается лёгкой вибрацией.
- «Скопировать код» (или касание цифр) копирует код через буфер обмена; если телефон не разрешает,
  появляется поле с выделенным кодом для ручного копирования.
- Кольцо показывает, сколько осталось из 5 минут. Когда время выходит, цифры гаснут, а страница
  предлагает запросить новый код на сайте. Если часы телефона сильно расходятся с сервером, точный отсчёт не рисуется.
- Фон: своя лёгкая светодиодная матрица (как на сайте). Касание пустого места пускает по ней волну.
- При «уменьшении движения» в системе анимаций нет, фон неподвижный.
